# Излом для Phasma

Излом построен по приложенному концепту. Корпус сложен вбок и вперёд, голова смещена под плечо, одна рука опущена почти до пола, вторая прижата к груди. В материале мокрый холст сочетается с пятнами грязи, потёртыми швами и бледной кожей.

## Подключение в Unity 6 URP

1. Скопируй папку Unity/Assets/Phasma/Izlom в Assets/Phasma/Izlom проекта.
2. В Unity открой **Tools → Phasma → Configure Izlom**. Команда выбирает Generic Rig, настраивает циклы, определяет путь к кости Root и создаёт материал URP/Lit. Скрипт рассчитан на путь Assets/Phasma/Izlom.
3. Возьми клипы из Izlom.fbx для своего Animator Controller. Укажи базовый темп 0,60 м/с на состоянии Walk_InPlace и выключи Apply Root Motion, когда объект перемещает NavMeshAgent.
4. Для Walk_RootMotion включи Apply Root Motion и убери параллельное продвижение Transform со стороны агента. Отдельный FBX с этим клипом можно импортировать с Generic Avatar от основной модели.

Для ручной настройки материала импортируй Base Color как sRGB, Normal как Normal Map, URP Mask как линейную текстуру с альфа-каналом. Используй URP Mask как Metallic Map и Occlusion Map. Канал R хранит Metallic, G хранит Occlusion, A хранит Smoothness. В Lit выбери Metallic Alpha источником Smoothness.

Документация Unity о настройках Generic Rig и упакованных картах. [Rig Import Settings](https://docs.unity3d.com/6000.0/Documentation/Manual/FBXImporter-Rig.html) · [URP channel packing](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/shaders-in-universalrp-channel-packed-texture.html)

## Клип и управление

| Клип | Длительность | Движение |
| --- | --- | --- |
| Idle | 4,20 с | Корпус замирает, длинная рука успокаивается, голова доворачивается с задержкой |
| Walk_InPlace | 1,60 с | Два шага, Root неподвижен. Контакт стоп рассчитан на прямое равномерное движение агента со скоростью 0,60 м/с |
| Walk_RootMotion | 1,60 с | Два шага на 0,96 м. Средняя скорость 0,60 м/с, мгновенная скорость меняется в течение шага |

Опора проходит через пятку, полную подошву и носок. Таз проседает после касания и догоняет шаг. Левая рука запаздывает за корпусом. Во время прямого движения Walk_InPlace схож с Walk_RootMotion при указанном темпе. На поворотах, при разгоне и при остановке контакт зависит от переходов Animator и фактической скорости агента.

Для реакции на игрока добавь IzlomGaze на объект с направлением вперёд персонажа, укажи кость Head и Transform игрока. Компонент мягко доворачивает голову после остановки NavMeshAgent и возвращает управление клипу при движении.

## Проверка

- Оба новых FBX повторно импортированы в Blender. Проверены кости, скиннинг основной модели, клипы, совпадение поз на границах циклов и смещение Root на 0,96 м.
- По кадрам FBX проверена неподвижность стопы в фазе полной опоры Walk_RootMotion. В превью камера зафиксирована, сетка размечена через 25 см. Цветные маркеры показывают фазу контакта левой и правой стопы.
- Unity Editor и сцена Phasma в рабочей среде отсутствовали. Импорт и работу скриптов в Unity предстоит проверить в проекте.
