# Исходные материалы

Анатомическая база, стандартный гуманоидный скелет, базовые меши одежды, обуви, волос, глаз, бровей и ресниц, а также часть исходных карт адаптированы из стандартных пакетов MakeHuman и MakeHuman Plugin for Blender. Для данных модели использованы материалы, опубликованные под CC0 1.0. Программный код MakeHuman и MPFB в комплект не входит.

- MakeHuman Community, [MakeHuman Plugin for Blender](https://github.com/makehumancommunity/mpfb2)
- MakeHuman Community, [MakeHuman System Assets](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)
- Creative Commons, [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

Индивидуальные пропорции, износ и цвет одежды, настройка сетки и весов, часы с экраном, тестовый фонарик, позы и сцена превью подготовлены для Phasma.
