# Проверка навигации — Unity 6000.6.3f1

## Получение и запуск
1. Закройте Unity. Сохраните собственные изменения коммитом, если они есть.
2. В GitHub Desktop нажмите Fetch origin, затем выберите feature/ghost-navigation в Current branch.
3. Откройте эту рабочую папку через Unity Hub. Дождитесь импорта и проверьте Console на ошибки компиляции.
4. Откройте Assets/Scenes/Prototype.unity. Включите Gizmos, выберите Ghost и нажмите Play.

## Кто чем управляет
- Floor / RuntimeNavigationWorld: Geometry содержит Floor MeshCollider и Wall BoxCollider. Moving Obstacles содержит DoorVisual BoxCollider. NavMesh строится при запуске; Bake вручную не требуется.
- Ghost / GhostNavigation: создаёт и настраивает NavMeshAgent, если он отсутствует; проверяет полный маршрут. GhostActor задаёт обычное движение, GhostHuntController — движение охоты. Значения прежних Inspector-полей сохранены.
- DoorVisual: препятствие вырезает свою область из NavMesh и обновляется при повороте двери. Призрак не открывает дверь специально ради прохода; при недоступной цели он останавливается.
- Room: горизонтальные границы комнаты ограничивают точки появления и обычного перемещения. Поиск во время охоты пока использует радиус вокруг последней известной позиции.

## Обязательные проверки (пока не выполнены в облаке)
1. Несколько запусков: призрак появляется в выбранной комнате, не на стене; нет сообщений no walkable spawn или ошибок NavMeshAgent.
2. Обычное перемещение: призрак остаётся в выбранной комнате, обходит Wall, останавливается на Idle и Interaction. Наблюдайте выделенный Ghost в Scene view — визуальной модели у него пока нет.
3. Охота: двигайтесь в поле зрения призрака; он преследует по маршруту. За Wall должен обойти препятствие, а не пересечь его. Вокруг концов стены оставлено пространство для обхода.
4. Потеря цели: перестаньте шуметь и скройтесь из поля зрения. Призрак ищет достижимые точки около последней позиции и завершает охоту по таймеру.
5. Дверь: откройте/закройте её. Через саму дверь призрак проходить не должен; он использует альтернативный путь, если тот есть. Текущая дверь стоит на открытом полу и сама по себе не изолирует комнаты.
6. Повторно проверьте подбор/бросок приборов, UV/EMF, книгу, датчик движения и защитную зону.
7. Остановите Play и запустите снова: NavMesh создаётся заново без накопления данных и компонентов.

Если есть ошибка, передайте полный текст первой ошибки Console и шаги воспроизведения. Красный текст компиляции и ошибка поведения — разные результаты.

## Откат
Закройте Unity и переключитесь на main в GitHub Desktop. Исходный коммит 9bbd013 сохранён в main. Не используйте Discard для незакоммиченной собственной работы.

## Исправление CalculatePath
При NullReferenceException в NavMeshAgent.CalculatePath обновите GhostNavigation.cs из ветки feature/ghost-navigation. Остановите Play перед заменой; дождитесь компиляции и запустите заново. Если ошибка повторится, выберите её и скопируйте весь стек из нижней панели Console (включая строки GhostNavigation.cs и GhostHuntController.cs).
